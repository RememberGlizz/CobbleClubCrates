# Local build dependency

CobbleClub Crates shares the main CobbleClub economy/key services.

Before building this repository, copy the current **CobbleClub main mod JAR** into this `libs/` directory. The Gradle build accepts versioned names matching `cobbleclub-*.jar`.

For the V3.8.4 / Cobblemon 1.8.0 source, use the matching CobbleClub V3.8.4 JAR.
